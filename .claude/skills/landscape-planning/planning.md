# Planning Frameworks

## The Site Planning Process

1. PROJECT INITIATION — Define goals, scope, budget, schedule; identify stakeholders
2. SITE INVENTORY — Collect data: survey, soils, ecology, utilities, zoning, history; base map preparation
3. SITE ANALYSIS — SWOT analysis; constraint and opportunity mapping; composite suitability analysis
4. PROGRAM DEVELOPMENT — Define uses, spaces, relationships; quantify areas, capacities, budgets; user needs assessment
5. CONCEPT / SCHEMATIC DESIGN — Bubble diagrams to concept plans; explore alternatives; client review
6. DESIGN DEVELOPMENT — Refine layout, materials, planting; preliminary grading and drainage; cost estimates
7. CONSTRUCTION DOCUMENTS — Detailed plans, sections, details, specs; permits and approvals
8. CONSTRUCTION ADMINISTRATION — Bidding, contractor selection; site observation and quality control
9. POST-CONSTRUCTION — Establishment period maintenance; performance monitoring and adaptive management

## Site Inventory Checklist

Natural Systems:
- Topography / contour survey (1' or 2' intervals)
- Soils map and on-site soil tests
- Hydrology: streams, wetlands, floodplains, drainage patterns
- Vegetation: tree survey (species, size, condition), plant communities
- Wildlife habitat assessment
- Climate data: temperature, precipitation, wind rose, sun angles
- Geology and bedrock

Built Environment:
- Existing structures, paving, walls, fences
- Utilities: water, sewer, gas, electric, telecom (above and below grade)
- Circulation: roads, paths, parking, access points
- Adjacent land uses and context

Regulatory and Cultural:
- Zoning, setbacks, easements, covenants
- Historic and cultural resources
- Environmental regulations (wetland buffers, endangered species)
- Views and visual character

## Program Development

The program defines what the design must accomplish:
- Use Zones — What activities will occur? (passive recreation, active recreation, circulation, parking, service, habitat preservation)
- Space Requirements — How much area does each use need?
- Adjacency and Separation — Which uses should be near each other? Which must be separated?
- User Profiles — Who will use the site? (ages, abilities, peak times)
- Performance Criteria — Measurable goals (e.g., manage 100-year storm on-site, provide 50% tree canopy)

## Master Planning

A master plan provides a long-term vision, typically implemented in phases:
- Phasing — Prioritize by need, budget, logical construction sequence
- Infrastructure first — Roads, utilities, grading set the framework
- Quick wins — Early phases should include visible, high-impact improvements
- Flexibility — Accommodate future changes in use, climate, community needs
- Living document — Revisit and update every 5-10 years
